# More Julia

This code was developed with Julia v1.9.3.

This part of the course uses a [Pluto.jl](https://github.com/fonsp/Pluto.jl) notebook,
based on the course
[Julia for High Performance Computing Course at HLRS 2022](https://github.com/carstenbauer/JuliaHLRS22).
Run

```bash
julia -e 'import Pkg; Pkg.activate("."); Pkg.instantiate(); import Pluto; Pluto.run()'
```

in this directory. Then, open the Pluto notebook `more_julia.jl`.
