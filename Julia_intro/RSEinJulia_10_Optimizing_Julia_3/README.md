# Optimizing Julia 3

This code was developed with Julia v1.9.4. Run

```bash
julia -e 'import Pkg; Pkg.activate("."); Pkg.instantiate(); import Pluto; Pluto.run()'
```

in this directory. Then, open the Pluto notebook `optimizing_julia_3.jl`.

This lecture is based on some posts in the Julia discourse forum
https://discourse.julialang.org/
